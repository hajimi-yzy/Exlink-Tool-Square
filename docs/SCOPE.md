# 示波器（1.0.15）

输入为 GPIO4 / ADC1_CH3，接口沿用 ROW1 的 pin1 GND、pin5 IN。
页面采用原生 480×480 布局，黑底、黄色曲线；STOP 后保留最后一帧。

| 选项 | 作用 |
| --- | --- |
| Time / div | 1、2、5、10、20、50 ms/格；横轴共 10 格 |
| V / div | 0.1、0.2、0.5、1.0 V/格；纵轴共 6 格 |
| Y base | 设置纵轴下沿，0～2 V、步进 0.5 V |
| Trigger | 自由运行、上升沿自动触发、下降沿自动触发 |
| Trig. level | 0.5～2.5 V；20 mV 迟滞，约 25% 前置窗口 |
| AUTO FIT | 根据最后一帧设置纵轴范围，不改变输入电路量程 |

显示 Min、Max、Vpp、Mean、RMS 和频率。RMS 包含直流分量；频率至少需要
两个完整且一致的周期、每周期至少 20 个采样点，否则显示 `--`。
没有找到触发边沿时继续刷新，并显示 `AUTO (NO EDGE)`。
改变时基/触发设置会清除旧帧，避免把旧数据标成新刻度。

采样率随时基使用 20、10、5、2.5、1 kSa/s，显示窗口为 `(点数−1)/采样率`。
ADC DMA 由一个按需启动的 FreeRTOS 工作任务处理，LVGL 每 100 ms 读取完整帧；
工作任务不操作界面或内部 I²C。STOP 立即返回，后台完成 DMA 释放。
ADC1 被示波器占用时，电池显示使用缓存，避免与 Arduino 单次采样冲突。
OTA 先暂停采样，结束或暂停失败后按原状态恢复；采样运行期间阻止自动休眠。

数值使用 ESP32-S3 eFuse 校准，表示 **ADC 引脚电压**。当前没有确认外部输入电路的
分压倍率与保护范围，不能据此将更高电压或负电压直接接到 ADC。
11 dB 校准特性范围约为 150～3100 mV，超出时显示 `ADC range!`；坐标范围
不等于可安全输入范围。采样率与频率显示也不能代表已验证的模拟带宽或防混叠能力。
丢样会丢弃不完整帧；持续错误显示重试提示，ADC 释放失败则要求重启。
