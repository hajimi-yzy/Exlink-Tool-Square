# BLE 与 UART

## 蓝牙模式

上电及休眠唤醒后蓝牙默认关闭。在 Settings → Phone connection 中开启 App link，
供手机读取设备信息、状态和日志。BLE Serial 页面用于 Nordic UART 串口桥接。
两种模式互斥；切换时断开连接并清空旧队列。

广播超时或连接无有效通信超时后，设备关闭蓝牙，需手动重新开启。App 前台轮询
属于有效通信，后台暂停轮询。OTA 和素材传输期间保持更新会话；协议见
[BLE 更新协议](BLE_UPDATE_PROTOCOL.md)。

蓝牙回调只读取遥测缓存，不格式化浮点数、不操作屏幕或串口。遥测格式化和模式
生命周期由应用循环处理，避免占用蓝牙任务栈或在回调中执行阻塞操作。

## UART 接线与显示

UART 连接应共地并交叉 TX/RX，电平需符合接口要求。串口和蓝牙串口的显示历史
限制为 4 KiB；不可打印字节转义仅影响显示，不改变实际传输内容。

## 回归检查

1. 确认上电不广播，手动开启 App link 后能重复读取信息、遥测和日志。
2. 反复开关 App link，再切换到 BLE Serial；确认连接和旧队列均被清理。
3. 测试广播超时、连接空闲超时和休眠唤醒，确认蓝牙不会自行重新开启。
4. 测试 App 前后台切换、OTA 断连恢复和素材传输，确认未完成数据不会激活。
5. UART 使用独立供电的从机，共地并交叉 TX/RX。在接收、切页时复位从机，
   并测试长数据和二进制字节；主机不应重启或越界。

启动日志中的 reset reason 可辅助区分异常：3 为 panic，6 为任务看门狗，
9 为 brownout。电气复位仍需结合供电和信号测量判断。
