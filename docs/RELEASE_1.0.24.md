# v1.0.24

2026-11-17，固件正式版本。Android App 沿用 0.4.0。本版集中修改休眠、触摸中断和内部 I²C 的故障处理。

## 修改

- INA226 启动识别改为有限重试，缺失时继续进入界面，由后台任务重试；屏幕初始化前将 CS 保持为高电平。
- 休眠期间禁用普通触摸 ISR，退出 GPIO 唤醒后恢复下降沿触发；触摸控制器恢复不再重配 INT 引脚，避免重新启用低电平中断。
- 保留短暂 GPIO 唤醒原因；休眠配置或进入失败时恢复界面，避免停在黑屏重试。
- 保留跨休眠轮询的触摸错误计数及退避时间，使故障恢复可以完成；唤醒触点增加隔离，降低误开页面按钮的概率。
- INA 运行配置改为单设备 RAM 缓存，避免反复切换休眠模式时提交 NVS；修正库的 RAM 容量计数及重复初始化边界。
- INA 遇到 NACK、短读或空读时作废本次测量，清除旧显示值并继续采样，故障间隔不计入容量积分。
- 增加生产函数、真实驱动、I²C worker 及 LVGL 的回归与故障注入测试，以及统一测试入口和 GitHub Actions 检查。

## 测试范围

17 类主机回归加一项旧缺陷反向验证，合计 **18/18 通过**。测试使用生产源文件或直接提取的生产函数；GPIO、Wire、FreeRTOS 时序、ESP 睡眠及部分硬件接口采用替身。测试通过不等于已完成整机长期电气可靠性验证。

| --- | --- |
| 启动与休眠 | 缺失/错误 INA、短 GPIO 唤醒、1000 次纯定时唤醒、时间回绕、GPIO 配置失败、I²C/BLE 暂停失败、恢复顺序及运行功能阻止休眠。 |
| 触摸与共享总线 | 连续触摸、传感器并发、错误退避、短读、断连与恢复、过期结果拒收、IRQ 所有权、唤醒触点及真实 LVGL 事件。 |

## 实机记录

同一生产代码的 1.0.24-rc1 已完成 USB 刷写及逐段校验，设备串口确认版本、触摸启用、原生 480×480 及内部 I²C 100 kHz。用户确认拨盘切页、触摸及短时休眠后的触摸唤醒正常。一次中键按压无响应，是否按到不确定，原因尚未确认。

已收到的连续日志中没有 panic 或运行时间回退，末段空闲堆约 212 KB，栈最小空闲约 5.3 KB。正式 1.0.24 与该实测候选采用相同生产代码，正式版镜像另行编译及校验。不能将候选的实机结果写成正式镜像已完成长期测试。

AHT20 在该测试板上未安装，本轮没有温湿度实机验收；MPU6050 也未获得独立实机读数验证。

## 已知限制

- 实机仍出现 I²C `Error 263`（事务超时），最长后台操作约 1002 ms；休眠前也记录到约 992 ms 的主循环间隔。超时后的读取及恢复能够继续，但不能判定总线稳定，也不能保证所有场景都无停顿。
- light sleep 后 USB 日志未自动恢复，物理重新插 USB 后可恢复；界面唤醒与 USB 日志恢复需要分别验证。
- 尚未复现或完成验证：客户拨盘偶发重启、充电插入黑屏、隔夜休眠及多轮长期唤醒。没有据此断言电气根因。
- 无明确 UP 报告时，唤醒触点隔离采用后备判断，可能等待约 1～2 秒解除，仍需实机检查首次点按。
- INA 后台初始化覆盖启动未识别；不自动重配已识别芯片后来掉电而丢失的配置。待确认 OTA 镜像若启动时 INA 缺失，仍按既有健康判定回滚。

## 下载与刷写

`firmware.bin` 为应用镜像，供兼容的 App OTA 使用；`exlink-1.0.24-usb-full.bin` 为完整 USB 镜像，从 **0x0** 写入，不能作为 OTA 应用上传。已有设备优先使用匹配分区的应用 OTA。完整镜像含 OTA 初始化数据，会重置当前启动槽选择。

硬件接线与 16 MB Flash 分区须与本工程匹配；升级前保留可回退固件。文件校验值随 Release 附件提供。
