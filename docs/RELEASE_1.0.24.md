## 未通过及待验证项

- 实机仍记录到 I²C `Error 263` 超时，最长后台操作约 1002 ms，休眠前出现约 992 ms 主循环间隔；超时后可继续读取，仍可能出现停顿。
- light-sleep 后 USB 日志未自动恢复，重新插拔 USB 后恢复。
- 拨盘偶发重启、插入充电线黑屏尚未复现；隔夜及多轮长期休眠唤醒尚未完成验证。
- 本轮未完成 MPU6050、AHT20 的独立实机读数验证；测试板未安装 AHT20。
- 无明确抬手报告时，唤醒后的首次操作隔离可能持续约 1～2 秒，仍需实机复核。
- INA 后台识别仅覆盖启动未识别场景；已识别芯片掉电后的配置恢复未覆盖。待确认 OTA 镜像在 INA 缺失时仍会按健康检查回滚。
